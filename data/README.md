# How to download the dataset

Use the WSB dataset as an example.

- [Download the zip](https://www.kaggle.com/datasets/gpreda/wallstreetbets-2022) to current folder.
- Unzip and you should see a `.csv` file (about 211 MiB)

Now you should be able to read the data.
